# Ceramics for All

A practical, research-backed handbuilding ceramics course with eight learning phases, exercises, knowledge checks, assessment rubrics, and visual inspiration.

## Structure

- `dist/` contains the static website.
- `.openai/hosting.json` contains the OpenAI Sites hosting configuration.
- Phase 1 is the root page; Phases 2–8 use their corresponding route folders.
